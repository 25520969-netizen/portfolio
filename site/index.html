The Escalation Referee

AI-powered leave approval (PNKK)

The LLM never makes the decision. A 13-stage rule engine based on the Vietnam Labor Code 2019 does.

  • 13 validation stages covering 8 leave types (Labor Code 2019 Arts. 112, 115; Social Insurance Law 2024); every failure maps to one of 30 error codes.
  • Qwen2.5-VL, served locally with Ollama, only reads supporting documents — type, dates, names, leave days.
  • An LLM agent parses natural-language requests, drafts escalations for the right approver and processes their reply; annual leave up to 2 days auto-approves when rules pass.
  • FastAPI/SQLite backend, 3-mode web app (Staff, Manager, Test), Docker Compose, 225 automated test functions and a 37-case correctness suite.
  • 13 stages
  • 8 leave types
  • 30 error codes
  • 225 tests
  • 37-case suite

DataMate 2.0

Vietnamese Text-to-SQL question answering · Zalo AI Challenge 2026

When two model answers disagree, the system abstains — because a wrong answer costs more than no answer.

  • Offline pipeline turning Vietnamese business questions into DuckDB SQL/Python over CSV, Excel and SQLite, with Qwen2.5-Coder-14B-Instruct-AWQ inside the 15B-parameter limit.
  • Safe-abstain strategy protects a +1/−1/0 penalized-accuracy score.
  • Sandboxed executor (whitelisted builtins, no network), deterministic data cleaning, Vietnamese text normalization and date resolution.
  • 146 unit tests cover the deterministic layers and run without a GPU or LLM.
  • ≤15B params
  • offline
  • 146 unit tests (no GPU needed)
  • +1/−1/0 scoring
